# 2027 中歐冬季旅程 App v4

## 核心架構
- `index.html`：App 介面與功能
- `trip-data.js`：唯一的行程資料來源；以後改行程主要改這裡
- `manifest.webmanifest`：加入手機主畫面的 PWA 設定
- `sw.js`：App Shell 快取
- `icon.svg`：App 圖示

## 維護方式
日後只改行程資料：
1. 開啟 `trip-data.js`
2. 修改 `TRIP_DATA.days`、`flights`、`hotels` 等資料
3. 不要直接把行程資料寫死在 `index.html`

## 攝影機位地圖
- 共用資料為 `TRIP_DATA.photoSpots`，包括唯一 `id`、`city`、`dates`、`placeKeys`、`name`、`lat`、`lng`、`direction`、`time`、`lens`、`note` 與 `source`
- `dates` 使用 `days.date` 的日期，`placeKeys` 使用 `places.key`，讓每日與景點入口同步同一份機位資料
- 圖釘是建議站位區域，非精密測量的腳架位置；構圖與焦段屬攝影建議，現場須依入口、路況與視角微調
- 攝影時段不增加必到活動，不更動原本日期、住宿、預約或出發時間；湖區晨拍與 Košice 午餐順拍可省略
- Leaflet 1.9.4 在開啟攝影分頁時才載入；OpenStreetMap 底圖依供應端 HTTP 快取規則使用，不由 Service Worker 預先下載或永久快取
- 外部地圖載入失敗不阻擋其他分頁；機位清單、拍攝方向與 Google 地圖位置連結仍可使用，並提供重試按鈕
- 更新資料或介面時，同步調整 `index.html` 的資料版本、Service Worker 註冊版本及 `sw.js` 的快取名稱／版本資源

## GitHub Pages
將整個資料夾內容放在 Repository 根目錄，即可用 GitHub Pages 發布。

## 圖片
圖片採外部 URL，App 不需要圖片資料夾。景點卡片提供來源頁或原圖連結；失效圖片會自動隱藏，不影響行程文字。部分舊有照片仍需在出發前逐張核對授權與來源。

## PWA
在支援的手機瀏覽器中開啟 GitHub Pages 後，可使用「加入主畫面／Add to Home Screen」。首次開啟後 App Shell 可快取部分頁面資源；外部圖片仍需網路。

## 文化、語言與遊記參考

- 四國 24 個問候／常用句與 48 個情境句皆在 `row[3]` 提供 `ipa` 和 `reading`；`row[2]` 保留使用情境。共用 `phraseRows` 讓每日與文化頁同步顯示。
- IPA 是參考分詞讀法；英文拼讀是自訂近似提示，以大寫表示詞重音。特殊母音、軟音、長音與標記說明集中在 `pronunciationGuide` 和各國 `pronunciationHints`，音系／教學參考分列來源，不宣稱逐句母語錄音校對。

- `countries[].situations` 共用每國 12 個情境的中文／當地語對照：匈牙利語、斯洛伐克語、波蘭語、德語。每日卡片與文化頁共用呈現，跨國日顯示當天途經的各國。
- 句型參考列於各國短句下方；部分依三人、兩間房的行程需求改寫，保留原文字母與重音符號。

- `TRIP_DATA.travelGuide` 共用四國問候、文化提醒、當地語情境及 15 篇遊記（13 篇中文、2 篇英文）；中文親身圖文優先，排除明確業配、招待及聯盟票券導購。每篇標示語言、文章／旅行日期、可見揭露與行程差異；遊記查核日期獨立保存在 `blogsCheckedDate`。
- 「文化／遊記」頁可依國家篩選；每日依跨境日期顯示文化小抄，景點依 `placeKeys` 顯示遊記。總覽與交通／住宿提供入口，搜尋涵蓋新增內容。
- 未標示實際旅行年份時不得以文章更新年份代替；非冬季遊記只作照片及補給線索，不套用路況、時間或活動。規則與舊遊記不同時以官方核對並保留說明。
- 更新時保留已確認的航班、住宿、每日時間軸及地圖只標示位置的行為；同步更新資料／SW 版本，核對日期到國家與景點 key。

## 每日跳轉與行程收合

- 總覽城市區塊提供各日期入口，以 `days.date` 對應 Day 編號，點選直接切換每日分頁並定位該日。
- 每日時間軸使用原生 `details`，首次預設全部展開；收合保留時間、名稱、類型與預估停留時間。每一天提供全部展開／收合。
- 收合狀態以日期、時間、類型與名稱識別，保存在目前瀏覽器；搜尋、分頁切換與重開頁面後恢復。未允許儲存時仍可當次展開／收合，不會同步其他裝置或其他訪客。
